# My Third Blog Post

Published on: 2026-10-22

This is my fourth post, and final before submitting the project. I do plan to continue working on it afterwards though.

## What I have done achieved with this project
1. **SDLC:** Prior to this project, I had never used Github, and had no idea on how to effectively create a professional project. 
2. **Agentic coding:** I had not used AI heavily on a project before, and this gave me a space to safely learn the best practices surrounding agentic coding.
3. **Deployment:** I learned how to deploy and host a live website, something that will no doubt be useful in the future.

## Shortcomings throughout the project
1. **Pace and Focus:** This project was an early and quick start into the course and showed how much effort will be required going forward. I will admit that I didn't put in as much effort or work as I had hoped.
2. **Difficulty with some aspects:** I found Github actions to be difficult to setup for a while, and didn't have my site continuously deploying for a while, but I hope it is working smoothly now.

## The future for this site
1. **Prior Mentions** As mentioned in post 3, Ihave some ideas for features to add to the site. I would love to have this as a collection of resources I use, and a general reference/timekill for any small project ideas I may have.
2. **Collaboration** Once I have sign ins and posting capabilities, it could be fun to add features for collaboration or get others to author posts on the site
